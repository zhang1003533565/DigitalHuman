# 管理后台数字孪生驾驶舱设计规范

## 目标

为景区数字人管理后台输出一套完整桌面端高保真设计图。所有页面沿用同一导航结构、顶部状态栏、视觉令牌和内容密度，仅根据业务任务调整主工作区。

## 画布与全局结构

- 画布：1440 × 1024，不包含浏览器外壳。
- 左侧导航：固定 208px 深墨蓝侧栏，分组结构与现有后台完全一致。
- 顶部栏：固定 56px，包含景区选择、实时运行状态、日期、告警和管理员入口。
- 主工作区：深蓝黑基底，以 16px 间距组织业务模块；页面标题 24px，正文 14px。
- 主色：`#071522`、`#0B2030`、`#19C4D2`、`#24D38A`。
- 状态色：正常绿、提醒蓝、预警黄、严重红；紫色仅用于模型或数字人能力标识。
- 分隔方式优先使用间距、排版和细线；玻璃效果与发光只用于实时状态、地图热点和选中项。
- 圆角 6–10px，禁止大面积胶囊化、卡片套卡片和无业务意义的装饰。

## 关键页面原则

- 数据总览：地图是唯一主画布，指标、告警、服务状态和趋势为辅助信息。
- 列表管理页：筛选与批量操作在同一工具条，表格使用稳定列宽和行级操作区。
- 配置页：左侧选择对象，右侧完成配置与预览；保存操作固定在标题区或底部操作栏。
- 数据分析页：先给结论与异常，再给趋势和明细，避免图表堆叠。
- 知识库页：采用目录树、文档列表、内容编辑三栏工作台。
- 直播页：发布状态、脚本队列和直播预览形成主次明确的工作流。
- 设置页：顶层能力标签统一，模型列表和当前配置保持双栏结构。

# 游客端移动端响应式设计

## 目标

修复游客端在 320–768px 宽度下出现的内容裁切、卡片重叠、固定底栏遮挡和多重滚动问题，同时保持现有桌面端视觉、功能、路由和数据流不变。

## 已确认方案

采用混合响应式布局：内容型页面使用自然纵向滚动，沉浸型页面保留应用式体验，但内部区域按可用空间重排。

不采用以下方案：

- 只追加局部 CSS 补丁：短期改动较少，但会继续叠加视口高度、绝对定位和页面滚动之间的冲突。
- 为移动端复制独立页面组件：控制力较高，但会造成组件、交互和业务状态的重复维护。

## 全局布局规则

### 单一滚动所有权

- 移动端页面只能有一个主要纵向滚动容器。
- 内容型页面由应用内容区滚动，页面内部不再创建同方向的整页滚动区。
- 聊天记录、下拉菜单等局部内容可以保留有限高度的内部滚动。
- 不使用 `100dvh`、页面 `overflow: hidden` 和子级 `overflow: auto` 的叠加来控制内容型页面。

### 底部导航与安全区

- 底部导航继续固定显示。
- 主内容底部至少预留 `移动导航高度 + safe-area-inset-bottom + 16px`。
- 所有主要操作、地图控件、卡片结尾和最后一条数据都必须能滚动到导航栏上方。
- 支持 iOS 安全区，不把安全区高度重复计算到页面与导航中。

### 响应式范围

- 重点验证：320、375、390、430、768px。
- 断点以内不产生横向页面滚动。
- 主要触控目标不小于现有 `--touch-target`。
- 文本放大、长用户名、长路线名称不应撑破卡片。

## 页面设计

### 首页

- 页面采用自然纵向滚动。
- 移除移动端 Hero 的 680px/800px 强制最小高度，内容高度由标题、规划表单和视觉素材共同决定。
- 390px 及以下规划表单使用单列；较宽手机可使用两列，但标签、输入框和按钮不得压缩到不可读。
- 数字人素材位于内容流的独立视觉区域，不覆盖规划表单。
- 灵感和路线卡片可保留横向滑动，但页面本身不得横向滚动。

### AI 导览

- 保留上下分区：上方为数字人舞台，下方为对话面板。
- 舞台使用稳定的比例和最小高度，不再通过聊天区的 `vh` 高度反向推算人物位置。
- 对话面板进入正常文档流，高度由内容和可用空间决定。
- 消息列表可以局部滚动；输入区和发送按钮保持可见且不被底部导航遮挡。
- 三个选择器可横向滚动，但需显示完整的当前选项和明确的可滚动边界。

### 路线推荐

- 移动端按“筛选 → 地图 → 已选路线摘要 → 站点时间线”的顺序纵向排列。
- 地图设置明确最小高度，不与下方内容共享绝对定位上下文。
- 路线摘要和时间线使用普通文档流，不允许覆盖地图或彼此叠加。
- 时间线连接线仅在每个节点内部定位，其高度由相邻节点间距决定，不能使用跨容器负值定位。
- 页面切换路线或筛选加载时保持布局高度稳定，空状态和错误状态占据正常内容区域。

### 景点地图

- 地图保持页面首要区域，移动端设置稳定的可视高度。
- 搜索、分类和地图控件保留在地图内部，但避开顶部导航、底部导航和系统安全区。
- AI 直播与附近服务在移动端进入地图下方的内容流，不再作为固定浮层覆盖地图。
- 选中景点时，详情卡可以作为地图内底部卡片出现，但必须限制高度、允许内容滚动，并位于移动导航上方。
- 地图服务未配置或加载失败时，错误提示仍应占据地图中心，不被其他卡片覆盖。

### 我的

- 保留现有纵向卡片结构。
- 页面使用单一自然滚动，并补足底部安全区。
- 头像、用户名和身份标签允许长文本换行或省略；统计卡片维持单列。
- 最后一张卡片能够完整滚动到固定底栏上方。

## 组件边界

- `App.css` 负责应用壳、主滚动容器、底部导航和安全区规则。
- 各页面 CSS 只负责页面内部重排，不重复定义应用级视口锁定。
- `VisitorTopNav` 和 `MobileBottomNav` 继续作为共享导航组件，不为本次适配复制移动端版本。
- 页面业务组件、请求逻辑、地图 SDK 初始化和路由不因响应式改造而改变。

## 状态与错误处理

- 加载、空数据、接口错误和地图未配置状态必须参与正常布局，不使用覆盖全屏的移动端定位。
- 页面内容增多时优先扩展滚动高度，不压缩主要操作区域。
- 局部滚动区需要明显边界，避免用户无法判断当前滚动的是页面还是卡片。

## 验证标准

### 自动验证

- 为响应式规则补充静态回归测试，检查移动端单一滚动、安全区、页面堆叠和禁止固定侧栏等约束。
- 运行游客端测试、ESLint 和生产构建。

### 代码级视觉检查

按用户要求不打开浏览器。本轮以用户提供的五张截图作为问题证据，通过代码和样式规则检查以下结果：

- 首页规划表单与后续内容可以连续滚动。
- AI 导览舞台、状态条和聊天面板不重叠。
- 路线地图、摘要和时间线严格按顺序排列。
- 地图直播卡和附近服务不再固定覆盖地图。
- 我的页面最后一张卡片不被底部导航遮挡。

浏览器像素级比对不属于本轮验证范围；后续如允许视觉验证，可在相同视口补充截图对比。

## 非目标

- 不改变桌面端信息架构和视觉主题。
- 不新增路由、业务功能、地图供应商或依赖。
- 不重做导航组件、不生成新图片素材。
- 不在本轮实现平板横屏专用布局；横屏只要求内容可访问、无重叠和无横向页面溢出。

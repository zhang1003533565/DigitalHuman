# 管理后台日间 / 夜间主题设计

## 目标

为管理后台与登录页建立同一套可持久化主题机制，支持按时间自动切换、手动选择日间或夜间，并消除现有页面中深色外壳与白色卡片、输入框混用的问题。

## 设计决策

### 主题模式

主题模式固定为三种：

- `auto`：07:00（含）至 19:00（不含）使用日间主题，其余时间使用夜间主题。
- `light`：始终使用日间主题。
- `dark`：始终使用夜间主题。

默认模式为 `auto`。手动选择会保存到 `localStorage`，并在登录页与后台之间共享。用户选择“自动”后重新按本地时间判断。

### 交互入口

- 登录页右上角新增主题切换器，与语言入口并列。
- 后台顶部栏日期旁新增主题切换器。
- 桌面端显示“自动 / 日间 / 夜间”三段选择；窄屏保留图标与无障碍标签，避免挤压导航。
- 切换即时生效，不刷新页面，不影响登录状态、当前路由或表单内容。

### 技术结构

- `AdminThemeProvider` 负责模式读取、时间判断、定时刷新、持久化和 Ant Design 主题算法。
- `AdminThemeSwitch` 只负责展示和更新模式，在登录页与后台顶部复用。
- 根节点通过 `data-admin-theme="light|dark"` 暴露最终主题，CSS 变量控制驾驶舱背景、面板、边框、文字和状态色。
- Ant Design 的 `defaultAlgorithm` 与 `darkAlgorithm` 负责表格、弹窗、抽屉、下拉框和表单控件的基础主题；项目 CSS 只处理品牌化外观与页面专项覆盖。

## 页面一致性规则

- 日间主题使用浅灰蓝工作区、白色面板、深色正文，保留青蓝色状态与主操作色。
- 夜间主题沿用现有深海蓝数字孪生驾驶舱风格，所有卡片、表格、输入框、下拉框、抽屉、弹窗与空状态都使用深色表面。
- AI 模型管理、数字人动作配置、数字人基础配置、知识库、游客反馈、问答记录、数字人直播和游览贴士必须逐页检查，禁止出现孤立白色大面板或不可读文本。
- 主题切换不得引入横向滚动；桌面端和 390 × 844 移动视口都要保持主要操作可见。

## 错误与兼容处理

- `localStorage` 不可用或值非法时回退到 `auto`。
- 时间定时器仅在页面挂载期间运行，并在卸载时清理。
- 首次渲染立即计算主题，避免登录页和后台之间切换时闪烁成错误主题。
- 不新增依赖，沿用 React、Ant Design 和现有 CSS 体系。

## 验证标准

- 自动模式在 07:00、18:59、19:00 三个边界得到正确主题。
- 手动日间和夜间选择可持久化，并覆盖自动判断。
- 登录页与后台共享同一模式和切换器。
- 所有管理后台路由在日间、夜间均无横向溢出、白底混搭或不可读控件。
- 登录页与后台在桌面和 390 × 844 视口完成浏览器视觉检查。
- 前端主题测试、现有 Node 测试、ESLint 和 Vite production build 全部通过。

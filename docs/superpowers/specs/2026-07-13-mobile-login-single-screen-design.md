# 移动端登录页单屏适配设计

## 目标

将游客登录与注册页改造成移动端单屏体验：页面始终限制在手机当前可视区域内，不允许页面级上下滑动或回弹；软键盘出现时自动压缩装饰区并将表单保持在可视范围内。

## 选定方案

采用 CSS 单屏布局与 `window.visualViewport` 动态同步结合的方案。CSS 负责移动端布局、紧凑状态和禁用滚动；登录页组件负责把真实可视高度与顶部偏移写入 CSS 自定义属性，覆盖仅依赖 `100dvh` 时部分移动浏览器软键盘适配不稳定的问题。

不采用整页比例缩放，因为缩放会降低文字可读性和触控目标尺寸；不采用仅 `100dvh` 的纯 CSS 方案，因为软键盘和浏览器工具栏变化时可能不能准确反映当前可视区域。

## 页面结构与内容取舍

桌面端保持现有布局与视觉不变。

在宽度不超过 768px 的移动端：

- 保留背景图、品牌标识、主标题、数字人主体和登录/注册卡片。
- 隐藏日期、时间、天气、品牌副标语、标题副图等次要信息。
- 缩小品牌、主标题、数字人展示区和卡片间距，但输入框与按钮保持至少 44px 高。
- 登录卡片完整显示在单屏下部；注册卡片使用更紧凑的标题、字段间距与操作区，仍不得通过页面滚动访问。
- 数字人仍作为视觉主体存在；换装按钮和气泡在正常移动状态可显示，空间不足或表单聚焦时隐藏。

## 单屏与滚动契约

移动端 `.auth-screen--tourism` 使用固定定位占据真实可视区域：

- 高度来自 `--login-viewport-height`，回退值为 `100dvh`。
- 顶部位置来自 `--login-viewport-offset-top`，回退值为 `0px`。
- `overflow: hidden`。
- `overscroll-behavior: none`。

固定定位、隐藏溢出和 overscroll 约束共同阻止背景拖动与回弹；不在页面祖先设置 `touch-action: none`，避免祖先触摸策略影响表单交互。表单控件使用 `touch-action: manipulation`，保证点击、输入、密码显隐和提交正常。登录页不得在移动媒体查询中重新设置 `overflow-y: auto`，也不得新增页面级或卡片级纵向滚动容器。

## 可视视口同步

`LoginPage` 为根 `<main>` 增加 ref。组件挂载后读取 `window.visualViewport`；若浏览器不支持，则使用 `window.innerHeight` 和零偏移。

同步函数写入：

- `--login-viewport-height: ${visualViewport.height}px`
- `--login-viewport-offset-top: ${visualViewport.offsetTop}px`

同步函数监听 `visualViewport` 的 `resize` 与 `scroll`，同时监听 `window.resize` 作为方向变化和无 VisualViewport 环境的回退。卸载时必须移除全部监听器。

## 软键盘和低高度状态

表单获得焦点时，通过现有 DOM 的 `:focus-within` 进入键盘紧凑状态，无需推测键盘类型：

- 隐藏标题图、副标题、数字人气泡和换装按钮。
- 压缩头部、舞台和卡片间距。
- 表单卡片占据主要可视空间并靠近视口顶部。
- 当前输入框、密码显隐按钮和提交操作保持可操作。

额外使用高度媒体查询覆盖横屏或矮屏：当可视高度不超过 680px 时，应用同一紧凑策略；当不超过 520px 时隐藏数字人展示层，只保留品牌和表单。该隐藏仅影响视觉层，登录、注册和认证逻辑不变。

## 登录与注册模式

- 登录模式保留现有用户名、密码、注册链接和提交按钮；不得新增“记住登录”等表单字段。
- 注册模式保留用户名、昵称、密码、确认密码、返回登录和提交按钮。
- 两种模式均必须在无键盘的常见移动视口中完整处于单屏。
- 软键盘出现时不允许页面滑动；通过真实可视高度、紧凑间距和装饰隐藏保持表单操作区域可见。
- 验证错误继续显示，但不得把页面撑出真实可视区域；错误文案采用紧凑行高并占用字段预留区域或覆盖原有间距。

## 可访问性与交互

- 输入框、按钮及密码显隐操作的有效触控尺寸至少为 44px。
- 禁用页面触摸拖动不得阻止表单控件的点击、聚焦、选择文字和提交。
- 方向变化、浏览器工具栏伸缩和软键盘关闭后，视口变量必须恢复到最新值。
- 不修改表单字段、接口、错误处理、数字人语音问候或登录后跳转逻辑。

## 测试标准

- 契约测试断言登录页根元素具有 viewport ref，组件监听并清理 `visualViewport.resize`、`visualViewport.scroll` 和 `window.resize`。
- 断言写入高度和顶部偏移两个 CSS 变量，并包含无 VisualViewport 回退。
- 响应式测试断言移动端登录页为固定单屏、`overflow: hidden`、`overscroll-behavior: none`，且不存在 `overflow-y: auto` 或祖先级 `touch-action: none`。
- 断言表单控件恢复 `touch-action: manipulation` 且触控高度至少 44px。
- 断言移动端隐藏次要头部信息，并存在 `:focus-within`、680px 和 520px 高度紧凑规则。
- 运行游客端全部 Node 测试、ESLint、TypeScript 与 Vite 生产构建。

## 完成标准

- 390×844 等常见手机视口中登录页无纵向滚动，登录卡片完整可见。
- 注册模式无页面滚动且所有必要字段与操作保留。
- 软键盘出现时页面不滑动，当前表单仍保持可操作。
- 横屏和低高度手机进入紧凑模式，不出现底部内容被永久裁切的问题。
- 桌面端视觉与行为无回归。
- 自动化测试、Lint 和生产构建全部通过。

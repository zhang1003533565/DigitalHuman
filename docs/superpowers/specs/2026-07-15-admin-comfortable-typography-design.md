# 管理后台大字号设计规范

## 目标

在不改变现有数字孪生驾驶舱布局、主题和功能结构的前提下，提高后台长时间使用时的可读性。重点解决菜单、表格、表单、辅助说明和状态信息大量使用 `8px`—`12px` 字号的问题，同时避免简单全局缩放造成表格拥挤、按钮截断或移动端横向溢出。

## 方案选择

采用“大字版”分层放大方案，而不是浏览器级整体缩放：

- 正文、表格单元格、表单控件、按钮：以 `15px` 为基准，长段落正文使用 `16px`。
- 侧栏菜单：`15px`；品牌副标题、状态说明等辅助文字最低 `13px`。
- 页面主标题：桌面 `24px`，移动端 `22px`。
- 顶栏标题：`21px`；卡片标题：`16px`。
- 指标标签与列表正文：`13px`—`15px`；指标数值保持原有视觉主次并提高到 `22px`—`26px`。
- 极小的装饰性刻度可保留 `11px`，但可操作信息和业务正文不得低于 `13px`。

未采用以下方案：

- 全局 `zoom` 或 `transform: scale()`：会破坏布局尺寸、模糊文字，并影响固定顶栏和弹层定位。
- 所有字号机械增加相同像素：会让标题、指标和辅助信息失去层级，移动端更容易溢出。

## 影响范围

统一调整以下后台界面：

- 登录页；
- 公共侧栏、顶栏、页面标题区；
- Ant Design 表格、表单、按钮、标签、分页、空状态、抽屉和弹窗；
- 总览驾驶舱、问答记录、景点管理、设施管理、数字人直播、AI 模型、知识库和系统设置等自定义页面；
- 日间与夜间主题；
- 390 × 844 移动端。

## 实现边界

- 在 `admin-cockpit.css` 中增加统一的后台排版令牌和组件覆盖，不新增依赖。
- 优先复用现有类名和 Ant Design 组件结构，不逐页复制字号规则。
- 字号变大后同步调整必要的行高、按钮高度、表格行高和紧凑区域间距，但不改变页面信息架构。
- 移动端允许页面纵向滚动；登录页仍保持单屏不可滚动。
- 表格可在自身容器内横向滚动，但页面根节点不得产生横向溢出。

## 验收标准

- 桌面后台主要业务正文与表格文字的计算字号不低于 `15px`，长段落正文不低于 `16px`。
- 可操作辅助信息的计算字号不低于 `13px`。
- 侧栏菜单计算字号为 `15px`，页面主标题桌面不低于 `24px`、移动端不低于 `22px`。
- 登录页、17 个核心后台路由在日间和夜间主题下保持布局稳定。
- 390 × 844 下导航、表格、表单、知识库和直播页面没有页面级横向溢出；登录页仍为单屏。
- Node 测试、ESLint 和 Vite production build 全部通过。

## 测试策略

- 先增加结构测试，锁定排版令牌、公共组件字号、移动端下限和禁止全局缩放。
- 浏览器读取代表性元素的计算字号，覆盖侧栏、顶栏、页面标题、表格、表单、按钮和辅助文字。
- 复核桌面 1280px 与移动端 390 × 844 的日间/夜间代表页面，并更新 `design-qa.md`。

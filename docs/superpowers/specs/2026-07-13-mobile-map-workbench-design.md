# 移动端地图工作台设计

## 目标

将游客端景点地图在移动设备上重构为“地图优先”的单屏工作台。地图保持主要视觉面积，搜索、分类、地图控制、数字人直播和附近服务按使用频率分层展示，解决当前按钮拥挤、文字竖排、直播与服务区域被压扁的问题。

本次仅调整移动端。桌面端双栏地图、直播卡和附近服务布局保持不变。

## 当前问题

- 分类按钮、搜索框、定位与缩放控制、五项地图操作同时覆盖地图，可用地图面积不足。
- 移动端底部操作栏宽度不足，按钮文字被压成竖排。
- AI 数字人直播卡与附近服务进入普通内容流后，在短屏上被压缩成不可用的细条。
- 地图、景点详情卡、内容卡和固定底部导航缺少清晰的移动端层级。

## 移动端信息架构

移动端由四层组成，按从底到顶排列：

1. 地图画布：占据顶部导航与底部导航之间的主要可视区域。
2. 地图工具：顶部搜索与分类、右侧定位与缩放、左下角上下文操作。
3. 服务抽屉：默认收起在地图底部，可展开查看数字人直播和附近服务。
4. 景点详情卡：选择景点后显示在服务抽屉上方，优先级高于普通服务内容。

底部全局导航保持固定，地图工具、服务抽屉和景点详情卡统一避开导航高度与安全区。

## 地图工具

### 搜索与分类

- 顶部使用一条横向工具栏。
- 分类入口收进工具栏左侧按钮，点击后展开横向分类选择面板或弹层。
- 搜索输入保持现有关键词、回车搜索与搜索按钮行为。
- 搜索结果存在时显示“清除结果”，清除后移除搜索标记并清空关键词。
- 分类与搜索不新增数据源，继续复用现有状态和处理函数。

### 定位与缩放

- 地图右侧只保留定位、放大、缩小三个圆形触控按钮。
- 每个按钮满足至少 44×44 像素触控面积并提供可访问名称。
- 指南针与比例尺保留，但尺寸和位置需要避开搜索栏、抽屉和底部导航。

### 上下文操作

- 删除移动端五项横向操作栏，防止文字竖排和地图遮挡。
- 左下角默认显示“景区中心”。
- 搜索结果存在时同时显示“清除结果”。
- “当前位置、放大、缩小”由右侧控制按钮承担，不重复展示。

## 服务抽屉

### 收起状态

抽屉停靠在地图底部、全局导航上方，仅显示一行摘要：

- 拖动提示条；
- AI 数字人在线状态；
- “附近服务”入口；
- 展开提示。

收起状态不得压缩地图，也不得出现直播卡被裁成细条的情况。

### 展开状态

展开后显示：

- AI 数字人直播标题、在线状态与现有三条讲解示例；
- “进入直播间”和“语音互动”两个现有入口；
- 停车场、卫生间、餐饮、游客中心、接驳车、医务点六项附近服务；
- “查看更多”入口保持现有语义。

展开高度受可视视口约束，抽屉内容可在自身内部纵向滚动，地图页面不产生横向滚动。

### 交互与可访问性

- 点击摘要或展开按钮打开抽屉。
- 点击遮罩、向下收起动作或按 Escape 关闭抽屉。
- 抽屉使用对话框语义，打开后焦点进入抽屉，关闭后焦点返回真实触发按钮。
- 展开状态、标题和关闭操作向辅助技术暴露。
- 遵守 `prefers-reduced-motion`，减少或关闭位移动画。

## 景点详情卡

- 桌面端继续使用地图坐标定位的信息卡。
- 移动端继续使用固定底部卡，但位置改为服务抽屉上方。
- 卡片高度有界并允许内部滚动，确保路线导航按钮始终可访问。
- 景点卡出现时不隐藏服务抽屉入口；两者不得相互覆盖底部导航。

## 响应式与视口规则

- 主要验收视口：375×667、390×844、430×932。
- 地图工作台使用动态可视视口高度，统一计算顶部导航、底部导航、安全区和抽屉停靠位置。
- 软键盘打开时，搜索工具栏保持可操作，不要求展开抽屉与键盘同时完整展示。
- 横屏下保持地图可用，服务抽屉最大高度进一步受限。
- 页面不得出现横向滚动、竖排操作文字、被压成细条的直播卡或遮挡底部导航的控件。

## 状态与数据流

- 新增的客户端状态仅包括移动服务抽屉的打开或关闭状态，以及移动分类面板状态。
- 地图实例、分类、关键词、搜索标记、已选设施和直播状态继续使用 `MapPage` 现有数据。
- 搜索、定位、缩放、景区中心、清除结果、直播跳转和语音互动均复用现有处理函数或路由。
- 不新增后端接口、持久化状态、页面路由或第三方依赖。

## 错误处理

- 地图 SDK 加载失败继续显示现有错误提示与重新加载按钮，提示位置避开移动工具栏。
- 定位失败继续使用现有反馈，不因抽屉状态丢失错误信息。
- 直播状态同步失败时，摘要和展开内容均显示“同步失败”，直播入口仍按现有路由行为处理。
- 无搜索结果时不显示无效的“清除结果”上下文按钮。

## 测试与完成条件

- 增加移动端抽屉状态和触发器契约测试。
- 更新响应式测试，验证地图占据主要视口、旧五项操作栏在移动端隐藏、工具按钮满足触控面积、服务抽屉停靠在导航上方。
- 覆盖 375×667、390×844、430×932、安全区和短横屏的静态布局计算。
- 验证服务抽屉与景点详情卡不会互相覆盖或遮挡底部导航。
- 验证桌面端 `map-side` 双栏布局和现有聊天、服务内容仍然存在。
- 运行全部 `*.test.mjs`、ESLint、TypeScript 与 Vite 生产构建、`git diff --check`。
- 按用户要求不打开浏览器；真实移动浏览器手势、软键盘和地图 SDK 视觉点验记录为非阻断验证缺口。

## 非目标

- 不改造桌面地图视觉。
- 不更换高德地图 SDK。
- 不新增附近服务详情页或服务检索接口。
- 不修改数字人直播业务逻辑。
- 不把地图页改成多页面流程。

# 管理后台大字号视觉验收

## 验收目标

在不整体缩放页面、不破坏既有数字孪生布局和双主题的前提下，提高后台全局文字可读性，并维持移动端登录单屏与后台页面可滚动能力。

## 设计基线

| 层级 | 目标字号 |
| --- | --- |
| 正文、表格、表单、按钮 | 15px |
| 长段落正文 | 16px |
| 可操作辅助信息 | 13px |
| 侧栏菜单 | 15px |
| 卡片标题 | 16px |
| 顶部标题 | 21px |
| 页面主标题 | 桌面 24px；移动端 22px |
| 关键指标 | 24px |

## 自动化契约

- `AdminThemeProvider` 的 Ant Design 全局字号为 `15px`，控件基准高度为 `38px`。
- `admin-cockpit.css` 使用语义化排版令牌统一公共框架和业务页面。
- 静态测试锁定桌面与移动端标题、菜单、表格、表单、长段落及登录页字号。
- 样式表不存在 `zoom` 或 `transform: scale()`。

## 桌面端浏览器验收

在 1280 × 720 视口下逐页复核以下 18 个后台路由的日间与夜间主题：

`dashboard`、`home-config`、`spots`、`spots/categories`、`spots/facilities`、`routes`、`travel-analytics`、`scenic-structured`、`voice-scripts`、`travel-tips`、`avatar`、`model-emotion`、`feedback`、`live-broadcast`、`qa`、`ai-models`、`knowledge`、`setting`。

结果：

- 共检查 36 个页面状态，侧栏菜单计算字号为 `15px`。
- 页面主标题计算字号为 `24px`。
- 表格、输入框与按钮计算字号为 `15px`。
- 问答详情计算字号为 `16px`；知识库正文子元素的 `16px` 级联规则由结构测试锁定。
- 默认设置页逐个检查当前可见直接文本节点，`13px` 以下项目数量为 `0`。
- 依次打开嵌入模型、语音音色、视觉模型、对话模型、多模态模型、手动维护和智能体编排 7 个设置标签；每个标签的可见文字与交互文字均没有 `13px` 以下项目，根节点横向溢出均为 `0px`。
- 设施新增抽屉已实际打开检查：业务提示、按钮和表单文字满足下限，页面横向溢出为 `0px`；高德地图版权与备案号沿用地图 SDK 的原生 `11px` 法务标识，不属于业务操作文字。
- 知识库富文本正文为 `16px`，表格单元格和行内代码为 `15px`。
- 页面根节点与 `.admin-content` 横向溢出均为 `0px`。
- 页面切换、主题切换和业务表单保持可操作，未出现因字号放大导致的遮挡或不可点击状态。

## 移动端浏览器验收

视口：390 × 844。

- 登录页文档高度与视口高度同为 `844px`，根节点宽度与滚动宽度同为 `390px`；输入框为 `15px`，标题为 `26px`，主题选项与语言按钮均为 `13px`。
- 登录表单范围为 `271.66px—622.34px`，提交按钮底边为 `622.34px`，完整处于 `844px` 视口内，没有被单屏裁切。
- 总览、设施、直播、问答、知识库和设置页面根节点横向溢出均为 `0px`。
- 页面主标题计算字号为 `22px`；问答表格和搜索输入框计算字号均为 `15px`。
- 后台内容区保留纵向滚动，宽表格的横向滚动限制在组件容器内部。
- 临时移动视口验收完成后已恢复桌面视口，并将主题模式恢复为“自动”。
